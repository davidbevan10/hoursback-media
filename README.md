# hoursback-media

Public image host for approved social creatives. Buffer fetches images from here via raw GitHub URLs.

Layout: `clients/<client>/<YYYY-MM-DD-post-slug>/slide-N.jpg` (or `image.jpg` for single posts).
Only approved creatives are published here. Do not add anything private.

URL pattern: https://raw.githubusercontent.com/davidbevan10/hoursback-media/main/clients/<client>/<post>/<file>
